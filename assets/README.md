# Assets

Source art and screenshots. Not synced into the game and not in the release zip.

- `logo/png/icon-*.png`: the addon icon at 64 to 512 px, drawn by `tools/make_icon.py` (no
  third-party libraries). The same script writes `Tanksign/media/icon.tga` (128x128, AddOns list)
  and `Tanksign/media/skull.tga` (white skull, tinted green or red in game for the on/off button).
- Concept: an ivory skull with gold trim, a small grey shield behind it, and a thin, mostly drained
  deep-red health bar below, on a near-black rounded square. Colors come from the Plain palette.
- Stage 6 adds the large logo with the name under it, and screenshots.
